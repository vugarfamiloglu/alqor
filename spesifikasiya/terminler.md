# Terminlər lüğəti

Alqor-un sənədlərində, xəta mesajlarında, Studio-da və kodda istifadə olunan
Azərbaycan dilində terminlər. Yeni söz əlavə edərkən əvvəlcə bu cədvələ baxın:
alınma sözün hərfi transliterasiyası (`debaq`, `bildmək`) əvəzinə dilin öz
sözü seçilir.

| İngiliscə | Alqor termini | Qeyd |
|---|---|---|
| debugger | **sazlayıcı** | `alqor sazla`, Studio → Sazlama menyusu |
| debugging, debug | **sazlama** | `jurnal.sazlama(...)`, «sazlama rejimi» |
| breakpoint | dayanma nöqtəsi | |
| linter | kod yoxlayıcısı | `alqorlint` |
| formatter | formatlayıcı | `alqorfmt` |
| documentation generator | sənəd yaradıcısı | `alqor sənəd` |
| compiler | kompilyator | |
| bytecode | bayt kodu | |
| virtual machine | virtual maşın | |
| runtime | icra mühiti | |
| interpreter | icraçı | `--motor py\|rs` |
| parser | təhlilçi (sənədlərdə), parser (mənbə kodunda) | |
| decorator | bəzəyici | `@bəzəyici` — § 5.11 |
| macro | makro | § 5.12 |
| query | sorğu | `sorğu hər ... son` — § 4.13 |
| actor | aktyor | § 9.12 |
| channel | kanal | § 9.13 |
| unit of measure | ölçü vahidi | `5 km` — § 3.8 |
| result type | Nəticə | `Uğur`, `Uğursuz` — § 7.5 |
| error propagation | xəta yayılması | `ifadə?` |
| case suffix | şəkilçi | `1-dən 10-a qədər` — § 4.14 |
| test block | sınaq bloku | `sınaq "ad" ... son` — § 13.3 |
| assertion | iddia, gözlənti | `iddia`, `gözlənilir` |
| precondition | ön şərt | `tələb` — § 5.13 |
| postcondition | son şərt (zəmanət) | `zəmanət` — § 5.13 |

> 2.5.1-dən etibarən köhnə adlar (`jurnal.debaq`, `alqor debaq`) ləqəb kimi
> işləməyə davam edir, lakin sənədlərdə yalnız yeni adlar istifadə olunur.
