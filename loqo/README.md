## İdeya

- **"q" hərfi** — Alqor adını ingiliscə *algor*-dan ayıran, Azərbaycan latın
  əlifbasına xas imza. Onun quyruğu alqoritmin axın xəttidir — kod
  yuxarıdan aşağı axır və irəli gedir.
- **Səkkizguşəli ulduz** — Azərbaycanın rəmzi; "q"-nun mərkəzində,
  dilin ürəyində.
- **Göy → firuzəyi gradient** — Azərbaycan bayrağının göy rəngindən
  Xəzərin firuzəyi rənginə keçid.
- Yazı (söz-nişan) şrift deyil, eyni xətt qalınlığı ilə çəkilmiş həndəsi
  formalardır — hər yerdə eyni görünür.

## Qaydalar

- İşarənin ətrafında ən azı onun eninin ¼-i qədər boş sahə saxlayın.
- 16 px-dən kiçik istifadə etməyin.
- Rəngləri, nisbətləri dəyişməyin, kölgə və effekt əlavə etməyin.
